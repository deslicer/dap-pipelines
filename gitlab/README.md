# GitLab CI templates

Reusable `.gitlab-ci.yml` fragments for installing `deslicer` from signed releases and running `deslicer change` commands.

Planned files:

- `deslicer.gitlab-ci.yml` — main reusable template
- `deslicer-multi-env.gitlab-ci.yml` — parallel-matrix variant for multi-environment reconcile

See Plan 1d Task 6 in the Deslicer-for-GitHub integration plan.
